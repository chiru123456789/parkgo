# 🚗 Smart Car Parking App — UI/UX Figma Prototype

An interactive 8-screen mobile application prototype for searching, selecting, and booking car parking spots in real-time.

## 🔗 Live Figma Links
* **Figma Design Canvas:** [https://www.figma.com/design/esSwVgXF3j8gSPVOYclHu8/ParkGo?node-id=0-1&t=zRvwfUWhU29tyLrJ-1]

## 📱 Included Screens & Flow
1. **Splash Screen** — Logo with auto-advance transition (2s delay).
2. **Onboarding Page** — Feature highlight with "Get Started" & "Skip" routing.
3. **Authentication Page** — Sign in / Sign up screen.
4. **Vehicle Profile Setup** — Car selection and license plate configuration.
5. **Home Map View** — Interactive parking location pins and bottom sheet carousel.
6. **Parking Spot Selector** — Level tabs (P1/P2) and visual bay selection grid.
7. **Checkout & Payment** — Duration picker, fee breakdown, and payment options.
8. **Digital Ticket** — Booking confirmation QR code and map navigation trigger.
